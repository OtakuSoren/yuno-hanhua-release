# YU-NO 正楷漢化

《この世の果てで恋を唄う少女 YU-NO》Steam版（App 912450）正楷漢化補丁。

- 底版：Steam「日文」語言版（depot 912453）
- 範圍：886 個腳本、95,559 句、約 187 萬字，劇情台詞、系統文字、選單全數翻譯完成
- 語音維持日文，僅替換文字與部分官方英文UI圖（操作說明頁等）

## 下載

安裝包放在本專案的 **Releases** 頁面（檔案較大，不放在一般的程式碼版本控制裡），
從右側 Releases 欄位下載 `YU-NO_正楷漢化_一鍵安裝.zip`。

## 安裝方式

1. Steam 資料庫右鍵 YU-NO → 內容 → 語言，切換成「日文」，等待下載/驗證完成
2. 解壓縮 `YU-NO_正楷漢化_一鍵安裝.zip`
3. 把解壓縮出來的所有檔案複製到 YU-NO 遊戲安裝目錄（跟 `Game.exe` 同一層）
4. 雙擊執行「一鍵安裝.bat」，依畫面指示確認即可

安裝包內附「還原成日文原版.bat」，可隨時還原成安裝前的日文版本。
詳細說明請見壓縮包內的 `README.txt`。
